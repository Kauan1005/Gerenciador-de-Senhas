# Gerenciador-de-Senhas
Gerenciador de senhas 100% client-side (HTML, CSS e JS puro) com criptografia AES-256-GCM e derivação de chave PBKDF2 no navegador. Backend via Supabase (Auth + Postgres com RLS). A senha mestra nunca é enviada nem armazenada — só um verificador cifrado. Inclui gerador de senhas, backup/restauração, import/export Excel e bloqueio automático.
